# 疑難排解

本文件整理 Windows 中文化管理程式常見問題。安裝與解除安裝的完整流程請先參閱 [INSTALLATION.md](INSTALLATION.md)。

## 找不到遊戲目錄

- 確認已安裝 Steam 版 Ultimate Edition（App ID `764300`）。
- 確認選擇的是遊戲根目錄，而不是 Steam Library 或其他上層資料夾。
- 若遊戲安裝在自訂 Steam Library，請依管理程式提示選擇實際目錄。

## 原廠檔案驗證失敗

可能原因：

- Steam 尚未完整下載或更新遊戲。
- 遊戲檔案已損毀。
- 已安裝其他會修改相同 PAK 的 MOD。
- 遊戲已更新，現有中文化版本尚未支援新的原廠基線。

建議處理方式：

1. 關閉遊戲與管理程式。
2. 透過 Steam 驗證遊戲檔案完整性。
3. 移除其他會修改相同檔案的 MOD。
4. 重新執行管理程式。
5. 若仍失敗，查看最新 Release 是否列出遊戲更新或相容性說明。

## Windows SmartScreen 顯示警告

安裝程式未使用 Authenticode 憑證簽署時，SmartScreen 可能顯示警告。請確認檔案只下載自本專案 GitHub Releases，並核對 Release 頁面列出的 SHA-256。

不要執行雜湊不符或來源不明的檔案。

## 安裝中斷或失敗

- 不要手動刪除 `.hghu-tw`。
- 不要直接覆寫遊戲 PAK。
- 再次執行同版本管理程式，依畫面提供的安全復原選項處理。
- 若程式拒絕繼續，請保留現況並回報錯誤代碼。

## 無法解除安裝

優先使用：

1. 原本下載的同版本 EXE。
2. 遊戲目錄 `.hghu-tw/installer/` 內的本機備援解除安裝程式。

若程式指出備份損毀或狀態不完整，請勿手動猜測覆寫。建立 Issue 並附上錯誤代碼與已去除私人路徑的畫面或紀錄。

## 遊戲更新後無法啟動或中文化失效

先不要重新安裝舊版中文化：

1. 查看最新 Release 與已知問題。
2. 使用可用的解除安裝程式還原原廠檔案。
3. 透過 Steam 驗證遊戲檔案完整性。
4. 等待支援新基線的中文化版本。

## 回報問題需要提供什麼

請使用「安裝器／解除安裝問題」Issue Form，並提供：

- 中文化管理程式版本
- Windows 版本
- Steam 遊戲檔案驗證結果
- 管理程式顯示的錯誤代碼
- 是否安裝其他 MOD
- 問題發生於安裝、解除安裝或還原的哪個階段
- 不含私人路徑與個人資料的畫面或紀錄

請勿上傳完整遊戲 PAK、官方完整原始文本、私人檔案或其他未經授權的遊戲內容。
